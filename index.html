DualShock / DualSense Input Recorder & Virtual Playback System
Python 3.12 ViGEmBus Pygame Multithreading JSON HID

A high-precision controller input recording and deterministic virtual gamepad replay application engineered for input benchmarking and automated testing on Windows.

  • Real-Time Hardware Capture (~120 Hz): Polls physical PlayStation controllers via SDL2/Pygame, supporting both DualShock 4 digital buttons and DualSense POV hat switches.
  • Protocol Normalization: Corrected non-linear trigger travel from raw ranges ([-1.0, 1.0] → [0.0, 1.0]) and translated stick coordinates to native 8-bit unsigned DualShock 4 HID distributions (0–255, center 128).
  • High-Precision Playback: Implemented a hybrid sleep/spin-wait timing loop to reduce cumulative timing drift during recorded input playback.
  • Virtual Controller Emulation: Integrated ViGEmBus to replay recorded inputs through an emulated DualShock 4 controller recognized by Windows.
  • Thread-Safe GUI: Decoupled capture and replay loops onto background worker threads protected by mutex locks, packaged into a standalone binary via PyInstaller.
